Bit für Bit – Computer Science

Help and contact · Last updated: November 2026 (version 1.0)

Bit für Bit is a learning app for computer science in years 9 and 10: 108 learning units – 36 short stations in nine topics (computers & hardware, spreadsheets, secure passwords, block coding, encryption, microcontrollers, encoding data, the internet, data & law), each on three levels. It works without internet, without ads and without accounts with the provider.

Contact

Questions, bugs or ideas? Write to smaehlmann.appdev@gmail.com. In the app you can also use Settings → “Send feedback”.

Getting started with a class

Once, on the teacher’s device

  1. On first launch choose “School” (later: gear → How it is used → Change) and set a password for the teacher area.
  2. In the teacher area, create a “New class”, e.g. “9b”. Optionally add a list of codes and set names to “Codes from the class list” – students then pick their code when joining instead of typing a name.
  3. “Show class code”: the QR code appears in large size, e.g. for the projector.

Once, on every student device

  1. Set up the app as “School” as well. Each device has its own password for the teacher area – easiest to use the same one everywhere. The devices are not connected to each other, so no internet is needed.
  2. Each student creates a profile with their own secure password. Several students can share one device.
  3. In the profile menu (circle with initials, top right) choose “Join a class” and scan the class code.

Collecting results – as often as you like

  1. Students show “Hand in progress” in their profile menu. If several share a device, “Hand in all profiles” on the login page is quicker: the codes change automatically and nobody has to log in.
  2. On the teacher’s device, open the class and choose “Collect results”. The camera stays on; every recognised code beeps and appears in the list. Collecting again simply updates the results.
  3. The overview shows every student and every topic, optionally per level, plus the stations the class finds hardest. “Export” gives you everything as a CSV file for spreadsheets.

Without a camera every code can also be copied and pasted as text. Classes and collected results are deleted automatically at the end of the school year (31 July).

Frequently asked questions

A child forgot their password.
In the parent or teacher area, choose “Reset password” for the profile. The child gets a one-time password and then sets a new, secure password.

The password for the parent or teacher area is forgotten.
For security reasons it cannot be recovered. Under “Forgotten the password?” all data on the device can be deleted; the app is then set up again.

How do results get to the teacher?
The teacher creates a class in the teacher area and shows the class code. Students use “Join a class” in their profile menu and show their code with “Hand in progress”. The teacher collects it with “Collect results” using the camera – directly from screen to camera, without internet.

The camera does not scan.
Check in the device settings that the app may use the camera. Alternatively, choose a photo of the code or copy and paste the code as text.

Do I need profiles?
No. With “Just start” you practise without profiles or passwords. Profiles can be set up later via gear → How it is used → Change; the stars collected so far are kept.

Where is the data, and how do I delete it?
Only on the device. Delete profiles and classes in the parent or teacher area, where you also find “Delete all data”. Removing the app deletes everything. More in the privacy policy.

Is there a school licence?
The app is a one-time purchase without in-app purchases. Schools get it through the app store’s volume purchase programme at the education discount.
