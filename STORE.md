## Hinweise für die App-Prüfung (App Review Information → Notes)

```
No login is required. On first launch choose "Einfach loslegen" (Just start) to use all exercises immediately.

To see the teacher area: Settings (gear icon) → "Profile einrichten" → "Schule" → set any area password (at least 12 characters, e.g. Blauer-Wal-sucht-7-Sterne) → create a profile.
In the teacher area a class can be created; its QR code is scanned by a student profile ("Klasse beitreten"). Results are handed in by QR code and collected with the camera ("Einsammeln"). Alternatively each code can be copied and pasted as text, so no second device is needed.

The camera is used only to scan these QR codes. The app makes no network connections and stores all data locally on the device.
The language can be switched with the flags at the top (German/English).
```
